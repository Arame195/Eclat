# Éclat — сайт ресторана (HTML / CSS / JS)

Никакой сборки не нужно — открывайте `index.html` в браузере или кладите
папку на любой хостинг / в существующий проект. GSAP и ScrollTrigger
подключены через CDN (cdnjs), React и Vite не используются.

## Структура

```
index.html      — вся разметка, одна страница
css/style.css   — все стили (токены + секции)
js/main.js      — все анимации (GSAP + ScrollTrigger, без сборщика)
images/
  hero/         — placeholder-фото первого экрана
  about/        — placeholder-фото блока «о нас»
  food/         — placeholder-фото 4 категорий тизера меню
  interior/     — placeholder-фото галереи «Атмосфера»
```

## Как заменить фотографии

Все изображения — подписанные placeholder SVG нужных пропорций. Чтобы
подставить свои фото:

1. Положите файл в соответствующую папку `images/...` (jpg/png/webp — не важно).
2. В `index.html` найдите тег `<img src="images/...">` и замените путь на новый файл.
3. Пропорции ориентировочно такие (не критично, используется `object-fit: cover`):

| Папка / файл | Пропорции |
|---|---|
| hero/hero-main | 4:5 |
| hero/hero-secondary | 4:5 |
| about/about-main | 4:5 |
| about/about-small-1, -2 | 1:1 |
| food/burger, pasta, desserts, coffee | 4:5 |
| interior/interior-1..5 | 7:5 |

## Как подключить меню

Ссылки-заглушки на меню (`href="#"`) находятся в трёх местах `index.html`,
все с комментарием рядом:

1. Fullscreen burger-меню — пункт «Меню» (`#navOverlay`).
2. Кнопка «Смотреть меню» в hero (`.hero__cta`).
3. Кнопка «Смотреть меню» в тизере (`.menu-preview__cta`).

Просто замените `href="#"` на реальный адрес/якорь, когда меню будет готово.

## Motion и доступность

Все анимации в `js/main.js` проверяют `prefers-reduced-motion` и
упрощаются/отключаются для пользователей с этой настройкой. Кастомный
курсор отключается на touch-устройствах, pinned-галерея «Атмосфера» — на
ширинах ≤780px (вместо неё — обычный горизонтальный swipe).
